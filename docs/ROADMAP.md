# Roadmap

## Now

Implemented today:

- canonical public GitHub repository input with audience, duration, and pitch goal;
- bounded Repository Intelligence with explicit limitations;
- deterministic ClaimLock and claim/evidence provenance;
- four-scene Story Manifest;
- separate story and production direction;
- repository evidence cards plus selective Livepeer image generation;
- required Livepeer Creative MCP estimate-before-execution flow;
- per-scene Livepeer TTS;
- five-criterion visual critic with one bounded repair;
- interactive HTML assembly with playback controls and narration fallback;
- Evidence and Production Receipts;
- filesystem development persistence and Upstash production persistence;
- reconstruction of delivered artifacts across fresh requests.

## Next

Reasonable post-hackathon improvements:

- make the production deployment publicly accessible without Vercel account authentication;
- support private repositories through explicit, scoped authorization;
- capture more repository-hosted screenshots and demo media as first-class evidence;
- expose estimate and actual-cost fields more prominently in the Studio receipt UI;
- improve recovery/resumption for partially completed production runs;
- add team review and approval before paid generation;
- add reusable brand and story preferences with explicit opt-in;
- expand end-to-end browser coverage and production observability.

## Later

Larger directions, not current features:

- richer timeline and scene editing;
- additional export and rendered-video formats;
- multi-repository or release-to-release stories;
- shared agency workspaces and reusable client systems;
- production analytics grounded in real run outcomes;
- broader evidence extraction for deployed products and APIs.

## Monetization hypothesis

This hypothesis is unvalidated. EchoPitch could offer a limited free/basic pitch, paid production runs, a recurring creator/founder plan, and a team or agency tier. Media-heavy tiers would need to reflect actual generation costs returned by the execution provider. No exact price, customer demand, revenue, or unit economics has been established.
